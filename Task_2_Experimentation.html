mlflow.set_experiment("car-price-regularization-sweep")

model_types = ['normal', 'lasso', 'ridge', 'polynomial']
momentum_options = [False, True]
methods = ['sto', 'mini', 'batch']
initialise_methods = ['zeros', 'xavier']
learning_rates = [0.01, 0.001, 0.0001]

SWEEP_EPOCHS = 500
SWEEP_SPLITS = 5

results = []

for model_type in model_types:

    if model_type == 'polynomial':
        Xtr = X_train_poly
    else:
        Xtr = X_train_np

    for use_momentum in momentum_options:
        for method in methods:
            for initialise_method in initialise_methods:
                for lr in learning_rates:

                    run_name = (
                        f"{model_type}_{method}_{initialise_method}"
                        f"_mom{use_momentum}_lr{lr}"
                    )

                    try:
                        with mlflow.start_run(run_name=run_name):

                            mlflow.log_params({
                                "model_type": model_type,
                                "method": method,
                                "initialise_method": initialise_method,
                                "use_momentum": use_momentum,
                                "momentum": 0.9,
                                "lr": lr,
                                "epochs": SWEEP_EPOCHS,
                                "cv_splits": SWEEP_SPLITS
                            })

                            if model_type == 'lasso':
                                regularization = Lasso(0.01)
                            elif model_type == 'ridge':
                                regularization = Ridge(0.01)
                            else:
                                regularization = NoRegularization()

                            model = LinearRegression(
                                regularization=regularization,
                                lr=lr,
                                method=method,
                                num_epochs=SWEEP_EPOCHS,
                                cv=KFold(
                                    n_splits=SWEEP_SPLITS,
                                    shuffle=True,
                                    random_state=42
                                ),
                                initialise_method=initialise_method,
                                use_momentum=use_momentum,
                                momentum=0.9
                            )

                            model.fit(Xtr, y_train_np)

                            cv_mse = float(np.mean(model.kfold_scores))
                            cv_r2 = float(np.mean(model.kfold_r2_scores))

                            mlflow.log_metric("cv_mse", cv_mse)
                            mlflow.log_metric("cv_r2", cv_r2)

                            results.append({
                                "model_type": model_type,
                                "method": method,
                                "initialise_method": initialise_method,
                                "use_momentum": use_momentum,
                                "lr": lr,
                                "cv_mse": cv_mse,
                                "cv_r2": cv_r2
                            })

                            print(
                                f"{run_name}: "
                                f"MSE={cv_mse:.4f}, "
                                f"R2={cv_r2:.4f}"
                            )

                    except Exception as e:
                        print(f"Run {run_name} failed: {e}")

results_df = pd.DataFrame(results)

results_df = results_df.sort_values(
    by=["cv_mse", "cv_r2"],
    ascending=[True, False]
)

Across the 144 configurations, model type had the biggest effect on performance. Normal linear regression and Lasso had CV MSE values around 0.07–0.09, while Ridge was much worse at around 0.6–2.4. This is mainly because the implementation applies regularization to the bias as well as the other parameters. Since log(selling_price) needs a large bias (around 13), Ridge's L2 penalty makes it harder for the model to reach the correct prediction scale. Lasso was less affected and therefore performed much closer to normal linear regression.

Stochastic updates with lr=0.01–0.001 worked best for normal linear regression, while full-batch updates with very small learning rates were too slow to converge within 500 epochs. Higher learning rates sometimes caused divergence. Xavier initialization and momentum only gave small and inconsistent improvements, which is expected for a simple linear model.

Polynomial features caused stability problems because the expanded features had values up to around 1400, compared with roughly -3 to 3 for the standardized original features. This caused several configurations to diverge and produce infinite loss. Applying a second StandardScaler after polynomial expansion fixed most of the problem, although the polynomial models still needed smaller learning rates to remain stable.
